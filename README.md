# CareerGhana Internship Projects

This repository contains three mobile applications developed during the CareerGhana internship. Each is an independent Expo and React Native application with its own setup instructions.

## Projects

1. [TaskFlow](./taskflow) - A local to-do app for creating, completing, editing, and reminding users about tasks.
2. [Voice Translator](./voice-translator) - An English-French translator with speech input and spoken translation output.
3. [FitTrack](./fittrack) - An offline fitness tracker for activity logs, history, and weekly step progress.

## Technologies

The projects use React Native, Expo SDK 57, TypeScript, and Expo Router. They also use AsyncStorage for local data where needed, with Expo Notifications, speech modules, the MyMemory Translation API, and chart-related React Native components for project-specific features.

## Setup

Open a project folder and follow its README for installation, required permissions, and run commands. The projects are separate applications, so install dependencies and start the development server from the relevant folder.
